# Состояние проекта

Обновлено: 10 ноября 2026 года.

## Текущий результат

Реализованы выплаты call/put, аналитическая цена Блэка — Шоулза и
Монте-Карло для европейских опционов без дивидендов. Монте-Карло возвращает
цену и стандартную ошибку, принимает число сценариев и явный seed.
Есть тесты, замеры скорости и приложение со сравнением методов.

После дополнения теста независимого расчёта среднего и стандартной ошибки
для call/put, двух знаков ставки и срока 1.5 года выполнена полная пересборка
с нуля без предупреждений компилятора; все 22 теста прошли.
Приложение и замеры скорости запущены. Для call при S = K = 100, r = 0.05,
σ = 0.20, T = 1, N = 100 000, seed = 42: цена 10.512032,
стандартная ошибка 0.046856; Блэк — Шоулз даёт 10.450584.
Замер на текущем компьютере: около 14.6 мс для 100 000 сценариев;
это ориентир, частота процессора меняется.

Пояснение с числовыми примерами, связью с C++ и вопросами для самопроверки:
`docs/monte_carlo_walkthrough.md`. Формулы, арифметика и соответствие коду
прошли независимую проверку; понимание пользователем ещё предстоит обсудить.
